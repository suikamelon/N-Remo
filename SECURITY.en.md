# Security Policy

[日本語](SECURITY.md) | English

## Supported Versions

As a general rule, only the latest stable version published in GitHub Releases is supported.

## Reporting a Vulnerability

If you discover a vulnerability, do not disclose its details in a public Issue before a fix is available. If GitHub Private Vulnerability Reporting is enabled, use the repository's **Security** page to submit a private report.

Include the affected version, reproduction steps, potential impact, and possible mitigations when available. Do not send real credentials such as Nature Remo, SwitchBot, Tuya, Cloudflare, or Firebase Tokens, Secrets, or passwords.

After reviewing the report, the maintainer will provide an acknowledgement, an assessment of the impact, and an expected fix schedule whenever possible.
